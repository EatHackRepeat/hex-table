The hex editor program is designed to provide an intuitive interface for viewing and modifying files at the byte level. Upon launching, the program opens a file, displaying its contents in both hexadecimal and ASCII formats side-by-side. 

The cursor, which is a crucial component of this editor, is planned to move independently within the data displayed on the screen. This functionality allows users to navigate through the file and select specific bytes or characters for editing without being confined to a particular section. 

In the current version, the cursor refreshes the screen, but the next iteration (V1.3) will address this limitation by enabling the cursor to move smoothly across both hexadecimal and ASCII representations, offering a more fluid editing experience. Users can highlight and modify individual values, append new values, or delete existing ones, providing full control over the file's content. When editing, the changes are reflected immediately in both the hexadecimal and ASCII sections, making it easy to track modifications in both formats simultaneously.
Additionally, version 1.3 will enhance the program's functionality by allowing users to delete files directly from the interface and write new files after modifications are made. A flashing cursor will be introduced to improve visibility and help users focus on the location of their edits. The file open function is already implemented, allowing users to press the F1 key to bring up a new screen, where they can enter a file name for opening. 
After editing, users can press the Escape key to exit the program, ensuring a clean and user-friendly exit process. This update aims to offer a more polished and interactive experience, making it easier for users to manipulate binary files with precision and efficiency.
